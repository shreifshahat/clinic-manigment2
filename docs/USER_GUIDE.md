# دليل الاستخدام المختصر لكل دور

> الواجهة عربية بالكامل واتجاهها من اليمين إلى اليسار.
> كل الأرقام المعروضةComing من قاعدة البيانات: **لا توجد بيانات وهمية**، وإذا لم
> توجد بيانات you'll see حالة فارغة واضحة.

## الدخول والخروج

1. افتح عنوان العيادة → شاشة الدخول (البريد + كلمة المرور).
2. الدخول يتم عبر Supabase Auth؛ الجلسة تُنتهي فورًا عند الضغط على **خروج**.
3. إذا مُنحت لك **كلمة مرور مؤقتة**، سيطلب النظام تغييرها قبل أي عمل آخر.

## صاحب العيادة

| الشاشة | ماذا تفعل فيها |
|---|---|
| **لوحة اليوم** | ملخص: مواعيد اليوم لكل الأطباء، المتحصَّل اليوم، المصروفات، آخر تقرير أسبوعي. |
| **الجداول** | اختر الطبيب ثم اليوم: كل المواعيد وحالاتها. |
| **الفواتير** | كل الفواتير ببنودها، إلغاؤها (مع سبب)، متابعة المتبقي على كل فاتورة. |
| **المدفوعات** | كل عمليات الدفع (نقد/فيزا) مع من حصّلها ومتى؛ إلغاء دفعة (مع سبب). |
| **المصروفات** | تسجيل مصروف (مبلغ، تصنيف، تاريخ، وصف)، تصنيفات، إلغاء مصروف. |
| **التقرير الأسبوعي** | آخر 7 أيام: إجمالي الفواتير، المتحصل فعليًا، المصروفات، صافي النتيجة، تفصيل يومي، وتوزيع التحصيل حسب طريقة الدفع. |
| **أداء الأطباء** | عدد المواعيد وحالاتها والقيمة الفاتورة لكل طبيب. |
| **الموظفون** | إنشاء حساب طبيب/ريسبشن (يُعاد لك **كلمة مرور مؤقتة مرة واحدة**)، تعطيل/تفعيل، إعادة تعيين كلمة المرور، عرض الجلسات وإنهاؤها. |
| **سجل التدقيق** | من فعل ماذا ومتى وبنتيجة، مع `request_id` لكل عملية. |
| **أوقات الأطباء** | تحديد ساعات العمل الأسبوعية، الاستراحات، الإجازات. |

**ملاحظات مهمة**
- لن ترى **أي** تشخيص أو علاج أو ملاحظات طبية — هذا مقصود. إذا احتجت معلومة
  سريرية فاطلبها من الطبيب المعالج (يمكنه منحك تفويضًا مسجّلًا على مستوى
  الزيارة نفسها، وهو ما ينتج في سجل التدقيق).
- في الشاشات المالية يظهر **اسم المريض فقط** دون رقم الهاتف.
- **لا تُعدّل** فاتورة أو مصروفًا بعد الاعتماد: استخدم **الإلغاء** (مع سبب) ثم
  سجّل قيدًا جديدًا — لأن السجل المالي يجب أن يبقى قابلًا للتدقيق.

## الطبيب

| الشاشة | ماذا تفعل فيها |
|---|---|
| **يومكم** | مواعيدك فقط، مع حالة كل موعد. |
| **مفالكم/المرضى** | مرضى مواعيدك فقط. لا يظهر مرضى الأطباء الآخرين. |
| **سجل الزيارة** | فتح سجل زيارة: الشكوى الرئيسية، التشخيص، العلاج، الملاحظات، القراءات الحيوية. ثم **تأكيد اكتمال الكشف** (يُغلق السجل ويحوّل الموعد إلى «مكتمل»). |
| **فواتيري** | فواتير العمل الخاص بك فقط. |
| **التفويضات** | منح طبيب آخر صلاحية الاطلاع على زيارة واحدة (مع سبب)، وطلب الصلاحيات الممنوحة لك. |

**ملاحظات**
- الملف الطبي ظاهر لك وحدك (وصاحب التفويض). لا يستطيع صاحب العيادة ولا
  الريسبشن رؤيته.
- يمكنك نقل الحالة: مؤكد → قيد الكشف → مكتمل. الإلغاء وتغيير الحالة
  غير المسموح بهما من دور الطبيب (قرار الريسبشن/صاحب العيادة) عدا «لم يحضر».
- عند الاستفسار عن حالة زميل، اطلب **تفويضًا** منه بدل قراءة ملفه.

## الريسبشن

| الشاشة | ماذا تفعل فيها |
|---|---|
| **الاستقبال** | مواعيد اليوم لكل الأطباء + الأوقات المتاحة + زر **حجز**. |
| **حجز موعد** | 1) اختر الطبيب 2) اختر التاريخ 3) اختر وقتًا متاحًا 4) ابحث عن المريض أو سجّل مريضًا جديدًا 5) احفظ. |
| **المواعيد** | تأكيد، إلغاء (مع سبب)، إعادة جدولة (مع سبب). |
| **المرضى** | البحث والتسجيل والتعديل. |
| **التحصيل** | إصدار فاتورة من قائمة الخدمات، تسجيل دفعة نقد/فيزا، متابعة المتبقي. |

**ملاحظات**
- لا تظهر لك أي معلومة طبية (تشخيص/علاج/ملاحظات) — ولا مطلقًا.
- عند تعارض الوقت يظهر تنبيه واضح **ويُحدَّث قائمة الأوقات المتاحة** مع اقتراح
  بدائل؛ الحجز الأصلي لا يتأثر.
- **لا تسجّل رقم البطاقة**: اكتب فقط طريقة الدفع ورقم العملية من جهاز الدفع
  (حقل `reference`). النظام يرفض أي رقم يشبه رقم بطاقة.
- الدفع بالبطاقة = **تسجيل** عملية تمت على جهاز الدفع؛ لا توجد بوابة دفع داخل النظام.

## موظف جديد (إنشاء الحساب من صاحب العيادة)

1. صاحب العيادة: «الموظفون» → «إضافة موظف» → الاسم والبريد والدور.
2. تظهر **كلمة مرور مؤقتة مرة واحدة** — سلّمها للموظف عبر قناة آمنة.
3. الموظف يسجّل الدخول بها، ويطلب النظام تغييرها فورًا.
4. عند مغادرة الموظف: «تعطيل» — تُنهى كل جلساته فورًا.

## أسئلة شائعة

| السؤال | الجواب |
|---|---|
| لماذا لا أستطيع فتح مريض ليس له موعد معي؟ | لأن الملف الطبي والبيانات مرتبطة بمواعيدك. اطلب من صاحب العيادة/الطبيب المعالج تسجيل موعد أو منح تفويض. |
| تظهر رسالة «هذا الموعد لم يعد متاحًا» | حجز شخص آخر نفس الوقت. حدّث الأوقات المتاحة واختر بديلًا. |
| نسيت تسجيل دفعة/فاتورة | لا تُعدّل: ألغِ السجل (مع سبب) وسجّل قيدًا صحيحًا. |
| نسيت كلمة المرور | صاحب العيادة: «إعادة تعيين كلمة المرور». |
| أريد إنهاء جلسة جهاز مسروق | صاحب العيادة: «الجلسات» → «إنهاء كل الجلسات». |
